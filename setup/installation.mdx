### Verify Node.js Installation

Check that Node.js and npm are installed correctly:

```bash Terminal
node --version
# Should output v20.x.x or higher

npm --version
# Should output 10.x.x or higher
```

<Note>
  Sistema Financiero requires **Node.js 20 or higher** due to Next.js 15 dependencies.
</Note>

## Installation Steps

<Steps>
  <Step title="Clone the Repository">
    Clone the Sistema Financiero repository from GitHub:

    ```bash Terminal
    git clone https://github.com/danielcarreon/sistema-financiero-app.git
    cd sistema-financiero-app
    ```

    <Info>
      If you prefer SSH, use: `git clone git@github.com:danielcarreon/sistema-financiero-app.git`
    </Info>
  </Step>

  <Step title="Install Dependencies">
    Install all required npm packages:

    ```bash Terminal
    npm install
    ```

    This will install all dependencies defined in `package.json`, including:
    - Next.js 15.5.4 (React framework)
    - Supabase client libraries
    - Chart.js for data visualization
    - Tailwind CSS 4 for styling
    - TypeScript 5 for type safety

    <Note>
      Installation typically takes 2-5 minutes depending on your internet connection.
    </Note>
  </Step>

  <Step title="Verify Installation">
    Confirm that all dependencies were installed successfully:

    ```bash Terminal
    npm list --depth=0
    ```

    You should see output listing all installed packages without errors.
  </Step>
</Steps>

## Development Scripts

After installation, you can use these npm scripts:

<CodeGroup>

```bash Development Server
npm run dev
# Starts Next.js development server on http://localhost:3000
# Includes hot-reload and fast refresh
```

```bash Production Build
npm run build
# Creates optimized production build
# Outputs to .next/ directory
```

```bash Production Server
npm run start
# Runs production build locally
# Requires 'npm run build' first
```

</CodeGroup>

<Warning>
  Do not run `npm run start` without first running `npm run build`. The production server requires a built application.
</Warning>

## Troubleshooting

### Common Installation Issues

<AccordionGroup>
  <Accordion title="Error: Node version too old">
    **Problem:** `The engine "node" is incompatible with this module.`
    
    **Solution:** Upgrade to Node.js 20 or higher:
    ```bash
    # Using nvm (Node Version Manager)
    nvm install 20
    nvm use 20
    
    # Or download from nodejs.org
    ```
  </Accordion>

  <Accordion title="Error: npm install fails with EACCES">
    **Problem:** Permission denied when installing packages globally.
    
    **Solution:** Fix npm permissions or use a Node version manager:
    ```bash
    # Option 1: Use npx instead of global install
    npx <package-name>
    
    # Option 2: Fix npm permissions
    mkdir ~/.npm-global
    npm config set prefix '~/.npm-global'
    echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
    source ~/.bashrc
    ```
  </Accordion>

  <Accordion title="Error: Module not found after installation">
    **Problem:** TypeScript can't find installed modules.
    
    **Solution:** Clear cache and reinstall:
    ```bash
    rm -rf node_modules package-lock.json
    npm cache clean --force
    npm install
    ```
  </Accordion>

  <Accordion title="Slow installation on Windows">
    **Problem:** npm install takes 10+ minutes.
    
    **Solution:** Disable Windows Defender real-time scanning for node_modules:
    1. Open Windows Security
    2. Go to Virus & threat protection settings
    3. Add exclusion for your project's `node_modules` folder
  </Accordion>
</AccordionGroup>
